# D 區 · 居家風險劇場

六段、135.007 秒雙直立屏展演，含 13 段 VoAI 旁白、母子對話與系統提示。左屏呈現空氣指標及角色字幕，右屏呈現透明框線廚房與紅色污染、綠色新風粒子。煙霧影片全程常駐。

## 業主分享

GitHub Pages：https://VistwinProject.github.io/D-Web/

首頁進入雙屏預覽，可切換 01–06、暫停、播放及重新開始。靜態預覽以同一瀏覽器的共用時鐘同步兩屏，不需要 Python 服務；沒有連接現場感測器或投影硬體。顯示數據為展演模擬。

語音預設開啟，按底部「播放」開始有聲劇場。預覽與完整舞台使用相同的底部播放列（`player-controls.js` / `.css`），135.007 秒後停在最後一幕，音軌與共用時鐘均不循環；按重播才重新開始。配音採用單一完整音軌，跟著展演暫停、續播、跳段及重設。雙屏內嵌頁不會重複播放；同一瀏覽器若開啟另一個劇場的聲音，前一個會自動靜音。字幕在左屏安全範圍內顯示，靜音時也能閱讀。

聲線：旁白「怡婷」、媽媽「婉婷」、孩子「軒軒」、空氣管家「文彬」，均為 VoAI Neo 預設。`voice-script.json` 保存逐句內容；`assets/audio/` 保存原始 WAV、135.007 秒完整音軌與 WebVTT 字幕。`show.json` 是共用分鏡與開關火時間表，`show-config.js` 為其瀏覽器版本。更新個別 WAV 後執行 `python tools/build_voice_show.py` 重建，並重啟本機同步服務。

### 設備與生活音效（2026-09-27）

預覽播放 `assets/audio/theatre-mix.wav`，原本純配音 `theatre-voice.wav` 與 13 段原始 WAV 仍保留。全場維持 135.007 秒：70.815 秒加熱後帶入鍋內煎炒聲，110.569 秒關火時結束；87.003 秒帶入排風扇實錄啟動與持續運轉聲；93.232 秒新風聲漸強啟動。排煙與新風持續至片尾，最後 4 秒淡出。有人說話時，音效降到原設定的 28%，前後平滑淡化，讓對白優先。

素材為網路 CC0 錄音，並非現場設備聲學量測。来源與處理方式見 [音效授權紀錄](assets/audio/sfx/CREDITS.md)。可在 `sound-effects.json` 調整音量、入點與淡入淡出，再執行 `python tools/build_voice_show.py` 重建；只需 Python 標準函式庫。`show.json` 的 `soundEffects` 保存解析後的實際秒數。

## 視覺與效能

大字幕與角色／設備圖示（2026-09-27）：左屏保留大字幕欄位，每句搭配旁白、媽媽、孩子或空氣管家的 SVG 圖示；依原配音起訖切短句並以約 0.8 秒淡入淡出（短句以時長四分之一為上限）；空檔留白、無提示符號，靜音時同樣顯示。句內切點為文字長度估算，非逐字辨識校準。右屏顯示 IH 爐、排煙、新風清淨圖示，依 `show.events` 切換待機、啟動中、運轉中或已關火；旋轉與發光依展演時間運作，暫停會凍結、重播會復位。圖示代表展演情境，未新增現場設備控制。樣式集中在 `captions.css`，邏輯在 `voice-captions.js` 與 `presentation-cues.mjs`。測試：`node --test tools/test_presentation.mjs tools/test_voice.cjs`。

中央 12 cqw 不放內容，兩屏各自保留分鏡編號。模型使用透明表面與框線，鏡頭放大 40%；90 顆紅色粒子與 55 顆綠色粒子。左屏不建立 WebGL renderer，縮小預覽依可見尺寸降低 3D 繪製解析度。背景影片跟隨播放／暫停，片尾保留最後畫面，不循環。

## IH 爐面獨立投影

分享網址：https://vistwinproject.github.io/D-Web/ih.html

純黑底、紅色發熱環、模擬功率、預估油煙溫度與 PM2.5 濃度。預設跟隨劇場；校正面板另有三段 60 秒獨立示範。所有數值為展演設定，沒有連接 IH 爐或感測器。

F 開啟校正面板：位置、尺寸、旋轉、梯形微調、亮度、鏡像與定位格線。空白鍵暫停數值，雙擊畫面進出全螢幕。設定儲存在此瀏覽器，可複製帶校正參數的網址。`?calibrate=1` 直接開啟面板。現場需依爐面尺寸和投影角度對位；CSS 梯形微調不是四角投影映射。

IH 投影修訂：9:14 直式舞台、正上方俯視透明圓角爐體；框內紅環與功率、框外溫度及濃度引線標示、IH 感應爐圖示。

爐體外框調整為 520 × 720 的單口爐比例，使用高亮完整雙層邊框，內部透明；爐圈保持正圓。

## IH 跟隨劇場（預設）

IH 預設跟隨劇場六段。01 紫色待機、02 綠色偵測、03 紅色加熱、04 琥珀色排煙、05 綠色新風、06 淺綠淨化。第 3 幕媽媽備餐對白結束才開火（70.815 秒），第 6 幕媽媽關火對白結束才熄環（110.569 秒）。其間持續加熱，排煙與新風可同時運作。失去同步超過 4 秒後顯示待機；外部數值接管時沿用外部 PM2.5。

本機 IH 透過 8776 的共用服務讀取分鏡。GitHub Pages 請在同一瀏覽器、同一網域分頁開啟 preview.html（或完整舞台 Dweb.html）與 ih.html；只提供該瀏覽器內同步，不跨裝置。多個預覽分頁各自同步其左右屏，IH 跟隨最近開啟／操作的劇場。校正面板仍可選獨立示範模式。

開發檢查：`python -m unittest discover -s tools -p 'test_*.py'` 與 `node --test tools/test_voice.cjs`。`preview.html?audio=muted` 可實際走音軌同步，但強制保持靜音，供無聲 QA 使用。

## 腳本運鏡與設備線框

`camera-shots.mjs` 採「全景 → 台詞重點特寫 → 全景」，每次轉場約 1.4–1.9 秒，特寫期間定住。沒有環繞或持續漂移。

| 語音事件 | 構圖 |
| --- | --- |
| 前言與開場 | 廚房全景 |
| 開始加熱 | 1.65 倍 IH 近景，隨後回全景 |
| 提醒切換排煙、啟動 | 1.6 倍抽油煙機近景，隨後回全景 |
| 潔淨新風啟動 | 1.45 倍新風入口近景，隨後回全景 |
| 關火對白 | 1.65 倍 IH 近景，隨後回全景 |
| 淨化回報與結尾 | 維持全景，最後語音結束後停留 4 秒 |

`camera-timeline.mjs` 依展演時間插值，暫停、跳段及重播同步；減少動態效果偏好時固定全景。時間依語音段落規劃，非逐字強制對齊。

`equipment-appearance.mjs` 控制 IH 外框、加熱環與鍋緣的灰 → 橘 → 紅漸變，關火後 8 秒緩退。抽油煙機啟動後漸亮為綠色，片尾淡回待機色。色彩表示展演設備狀態，不代表實測溫度。

驗證：`node --test tools/test_camera.mjs tools/test_presentation.mjs`。
